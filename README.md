# WaveReverse

Інтерактивний веб-додаток та математичний симулятор, розроблений для гейміфікації процесу вивчення, візуалізації та аналізу властивостей математичних функцій.

## Основний функціонал:
- Режим «зворотної реконструкції»: підбір та налаштування аналітичного рівняння під заданий еталонний графік.
- Інтерактивна декартова площина з підтримкою динамічного масштабування (Zoom) та панорамування (Pan) мишею.
- Безпечний синтаксичний аналіз (парсинг) та валідація введених користувачем виразів у реальному часі без перезавантаження сторінки.
- Розумна система оцінювання (Scoring System) для розрахунку точного відсотка збіжності кривих на основі геометричного аналізу точок.
- Плавна візуальна трансформація графіків (Morphing) при зміні коефіцієнтів за допомогою лінійної інтерполяції (Lerp).
- Оптимізований конвеєр рендерингу з автоматичним відсіканням невидимих зон та динамічним кроком дискретизації.

## Технологічний стек:
- HTML5 (Canvas 2D API)
- CSS3
- JavaScript (Vanilla JS, ES6+ / ES Modules, Math.js)
